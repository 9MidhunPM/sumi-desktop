# Asset provenance

Sumi's Ember (warm), Tide (cool), and Ink (monochrome) landscapes are original
vector artwork created for this repository by Midhun P M, licensed under the
root MIT license. Editable SVG sources accompany the 2560 × 1600 PNG exports;
JPEG thumbnails are derived from those exports. No external image downloads
are needed at installation or runtime.

The 22 imported palette presets retain their reusable color values and names.
Their original wallpaper images, thumbnails, private paths and provenance
claims were excluded before the initial commit. They now use one of the three
original landscapes with matching widget placement. Imported user wallpapers
stay in the user's private XDG data directory and are never added to this repo.

Interface SVGs are original MIT-licensed drawings except the Arch mark.
Its attribution and permissive license are in
[shell/assets/icons](../shell/assets/icons/README.md). Arch Linux retains its
trademark rights; this project is independent of Arch Linux and Hyprland.

The initial source-import history included the OpenAI knot from Simple Icons
v14.15.0 under CC0, attributed by its accompanying README; it was removed with
the personal integrations. Current releases contain no assistant branding.

Repository screenshots must show these distributable landscapes and synthetic
content only. Offscreen component renders are labeled as such and are not
proof of a native Wayland session.
