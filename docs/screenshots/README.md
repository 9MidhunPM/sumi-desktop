# Native release captures

Captured by `scripts/native-smoke.py` from the actual Sumi QML shell on a private
Hyprland 0.56.2 session, using a 1600 × 1000 headless output after nested renderer
initialization. No image generation, compositing, or retouching was used.

Ember and Tide are original MIT-licensed wallpapers included in this repository.
The application, priorities, and notification content are synthetic. Brightness
and night-light availability use explicit test fixtures; the system bus and
physical audio/network/Bluetooth devices are isolated. Dates and clock values
are the actual capture time.

These captures demonstrate native rendering, glass, and layout. They are not
proof of physical hardware control, display-manager startup, or battery impact.
